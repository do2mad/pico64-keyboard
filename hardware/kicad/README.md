# Pico64 Keyboard – KiCad project (PCB V2)

Open `Pico64-keyboard-V2.kicad_pro` with **KiCad 10**. Everything the project needs is in this
folder: the symbol library `Pico64-keyboard-V2.kicad_sym`, the footprints in
`Pico64-keyboard-V2.pretty/` and the 3D models in `3d/` – the library tables use `${KIPRJMOD}`,
so no global libraries are required.
